# Hive Smart Contracts Wiki

**Calling the chain from an app or an agent:** start with the [agent and developer quickstart](Home.md#agent-and-developer-quickstart) (JSON-RPC reads, Hive `custom_json` writes, and a signing note).

**Getting started with Engine smart contract development**: first, read all the links below in the **General System Design & Usage** section. After that, read the [Smart Contract Developer's Guide](https://github.com/hive-engine/hivesmartcontracts-wiki/blob/main/Smart-Contracts-Guide.md), which contains quickstart instructions and teaches you best practices for working with & testing smart contract code. Use the **Contract Documentation** section as a reference for individual smart contract interfaces.
